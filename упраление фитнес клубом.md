# Управление фитнес-клубом

**Описание:** Система для управления тренерами, клиентами, групповыми занятиями и записями клиентов.

---

---

## 📌 Идентификация сущностей и атрибутов

1. **Клиенты (Clients)**
2. **Тренеры (Trainers)**
3. **Групповые занятия (Group Classes)**
4. **Записи (Enrollments)**

---

### **📄 Clients**

 | ClientID          | INTEGER          | PK, NOT NULL, UNIQUE             |

### **📄 GroupClasses**
**Описание:** Хранит информацию о типах групповых тренировок, доступных в фитнес-клубе. Является справочной таблицей, содержащей шаблоны занятий без привязки к конкретному времени и тренеру.

#### **Атрибуты:**
 | Название          | Тип данных       | Ограничения                     |
 |-------------------|------------------|----------------------------------|
 | ClassID           | INTEGER          | PK, NOT NULL, UNIQUE             |
 | ClassName         | VARCHAR(100)     | NOT NULL, UNIQUE                 |
 | Description       | TEXT             | -                                |
 | DurationMinutes   | INTEGER          | CHECK(DurationMinutes > 0)       |
 | MaxCapacity       | INTEGER          | CHECK(MaxCapacity > 0)           |

#### **Ограничения:**
- `PK_GroupClasses`: PRIMARY KEY (ClassID)
- `UQ_ClassName`: UNIQUE (ClassName)
- `CHK_DurationPositive`: CHECK (DurationMinutes > 0)
- `CHK_CapacityPositive`: CHECK (MaxCapacity > 0)

---
Table Name: ClassSchedules

Description: Хранит информацию о конкретных временных сеансах групповых тренировок. 
Каждый сеанс привязан к типу занятия, тренеру, времени, залу и имеет максимальную вместимость.

Attributes:
- ScheduleID (SERIAL, PK, NOT NULL, UNIQUE)
- ClassID (INTEGER, FK (REFERENCES GroupClasses), NOT NULL)
- TrainerID (INTEGER, FK (REFERENCES Trainers), NOT NULL)
- Room (VARCHAR(30), NOT NULL)                                  - НОМЕР ЗАЛА
- StartTime (TIMESTAMP, NOT NULL)                               - ДАТА И ВРЕМЯ НАЧАЛА
- EndTime (TIMESTAMP, NOT NULL)                                 - ДАТА И ВРЕМЯ ОКОНЧАНИЯ
- MaxCapacity (INTEGER, DEFAULT 15, CHECK(MaxCapacity > 0))    - МАКС. УЧАСТНИКОВ

Constraints:
- PK_ClassSchedules: PRIMARY KEY (ScheduleID)
- FK_ClassSchedules_GroupClasses: FOREIGN KEY (ClassID) REFERENCES GroupClasses(ClassID) ON DELETE CASCADE
- FK_ClassSchedules_Trainers: FOREIGN KEY (TrainerID) REFERENCES Trainers(TrainerID) ON DELETE SET NULL
- CHK_ScheduleTime: CHECK (StartTime < EndTime)                 - НАЧАЛО РАНЬШЕ КОНЦА
- CHK_ScheduleMaxCapacity: CHECK (MaxCapacity > 0)              - ВМЕСТИМОСТЬ > 0
- UQ_ScheduleUnique: UNIQUE (ClassID, TrainerID, StartTime)     - НЕТ ДУБЛЕЙ

### **📄 Enrollments**
**Описание:** Таблица для реализации связи многие-ко-многим между клиентами и групповыми занятиями. Фиксирует факт записи конкретного клиента на конкретное занятие к конкретному тренеру с указанием статуса и даты записи.

#### **Атрибуты:**
 | Название          | Тип данных       | Ограничения                     |
 |-------------------|------------------|----------------------------------|
 | EnrollmentID      | INTEGER          | PK, NOT NULL, UNIQUE             |
 | ClientID          | INTEGER          | FK (REFERENCES Clients), NOT NULL|
 | ScheduleID        | INTEGER          | FK (REFERENCES GroupClasses), NOT NULL |
 | TrainerID         | INTEGER          | FK (REFERENCES Trainers)         |
 | BookingDate       | TIMESTAMP        | DEFAULT CURRENT_TIMESTAMP        |
 | Status            | VARCHAR(20)      | DEFAULT 'подтверждена', CHECK(Status IN ('подтверждена', 'отменена', 'посещена', 'не явился')) |

#### **Ограничения:**
PK_Enrollments: PRIMARY KEY (EnrollmentID)
- FK_Enrollments_Clients: FOREIGN KEY (ClientID) REFERENCES Clients(ClientID) ON DELETE CASCADE
- FK_Enrollments_Schedule: FOREIGN KEY (ScheduleID) REFERENCES ClassSchedules(ScheduleID) ON DELETE CASCADE
- UQ_EnrollmentUnique: UNIQUE (ClientID, ScheduleID) - КЛИЕНТ НЕ ЗАПИШЕТСЯ ДВАЖДЫ НА ОДИН СЕАНС
- CHK_EnrollmentStatus: CHECK (Status IN ('подтверждена', 'отменена', 'посещена', 'не явился'))

## 🔗 Взаимосвязи

Взаимосвязи:

● Clients и Enrollments (1 : M): Один клиент может записаться на множество сеансов, 
  но каждая запись относится к одному клиенту.
  ○ Enrollments.ClientID → Clients.ClientID

● ClassSchedules и Enrollments (1 : M): Один сеанс может содержать множество записей клиентов, 
  но каждая запись относится к одному сеансу.
  ○ Enrollments.ScheduleID → ClassSchedules.ScheduleID

● GroupClasses и ClassSchedules (1 : M): Один тип занятия может проводиться множество раз 
  (в разных сеансах), но каждый сеанс относится к одному типу занятия.
  ○ ClassSchedules.ClassID → GroupClasses.ClassID

● Trainers и ClassSchedules (1 : M): Один тренер может вести множество сеансов, 
  но каждый сеанс ведёт один тренер.
  ○ ClassSchedules.TrainerID → Trainers.TrainerID
