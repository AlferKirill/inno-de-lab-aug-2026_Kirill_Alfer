# Управление фитнес-клубом

**Описание:** Система для управления тренерами, клиентами, групповыми занятиями и записями клиентов.

---

---

## 📌 Идентификация сущностей и атрибутов

1. **Клиенты (Clients)**
2. **Тренеры (Trainers)**
3. **Групповые занятия (Group Classes)**
4. **Записи (Enrollments)**

---

---

## 🗃️ Проектирование таблиц

---

### **📄 Clients**
**Описание:** Хранит информацию о клиентах.

#### **Атрибуты:**
   Название          | Тип данных       | Ограничения                     |
 |-------------------|------------------|----------------------------------|
 | ClientID          | INTEGER          | PK, NOT NULL, UNIQUE             |
 | FirstName         | VARCHAR(30)      | NOT NULL                         |
 | LastName          | VARCHAR(30)      | NOT NULL                         |
 | Phone             | VARCHAR(20)      | UNIQUE, NOT NULL                 |
 | Email             | VARCHAR(100)     | UNIQUE                           |
 | RegistrationDate  | DATE             | DEFAULT CURRENT_DATE             |

#### **Ограничения:**
- `PK_Clients`: PRIMARY KEY (ClientID)
- `UQ_ClientPhone`: UNIQUE KEY (Phone)
- `UQ_ClientEmail`: UNIQUE KEY (Email)

---

---

### **📄 Trainers**
**Описание:** Хранит информацию о тренерах.

#### **Атрибуты:**
 | Название          | Тип данных       | Ограничения                     |
 |-------------------|------------------|----------------------------------|
 | TrainerID         | INTEGER          | PK, NOT NULL, UNIQUE             |
 | FirstName         | VARCHAR(30)      | NOT NULL                         |
 | LastName          | VARCHAR(30)      | NOT NULL                         |
 | Phone             | VARCHAR(20)      | UNIQUE, NOT NULL                 |
 | Spezialization    | VARCHAR(100)     | -                                |
 | HireDate          | DATE             | DEFAULT CURRENT_DATE             |
 | IsActive          | BOOLEAN          | DEFAULT TRUE                     |
 | ExpirienceYears   | INTEGER          | CHECK(ExpirienceYears >= 0)       |

#### **Ограничения:**
- `PK_Trainers`: PRIMARY KEY (TrainerID)
- `CHK_trainerExpirience`: CHECK (ExpirienceYears >= 0)
- `CHK_TrainerHireDate`: CHECK (HireDate <= CURRENT_DATE)

---

---

### **📄 GroupClasses**
**Описание:** Хранит информацию о типах групповых тренировок, доступных в фитнес-клубе. Является справочной таблицей, содержащей шаблоны занятий без привязки к конкретному времени и тренеру.

#### **Атрибуты:**
 | Название          | Тип данных       | Ограничения                     |
 |-------------------|------------------|----------------------------------|
 | ClassID           | INTEGER          | PK, NOT NULL, UNIQUE             |
 | ClassName         | VARCHAR(100)     | NOT NULL, UNIQUE                 |
 | Description       | TEXT             | -                                |
 | DurationMinutes   | INTEGER          | CHECK(DurationMinutes > 0)       |
 | MaxCapacity       | INTEGER          | CHECK(MaxCapacity > 0)           |

#### **Ограничения:**
- `PK_GroupClasses`: PRIMARY KEY (ClassID)
- `UQ_ClassName`: UNIQUE (ClassName)
- `CHK_DurationPositive`: CHECK (DurationMinutes > 0)
- `CHK_CapacityPositive`: CHECK (MaxCapacity > 0)

### **📄 Enrollments**
**Описание:** Таблица для реализации связи многие-ко-многим между клиентами и групповыми занятиями. Фиксирует факт записи конкретного клиента на конкретное занятие к конкретному тренеру с указанием статуса и даты записи.

#### **Атрибуты:**
 | Название          | Тип данных       | Ограничения                     |
 |-------------------|------------------|----------------------------------|
 | EnrollmentID      | INTEGER          | PK, NOT NULL, UNIQUE             |
 | ClientID          | INTEGER          | FK (REFERENCES Clients), NOT NULL|
 | ClassID           | INTEGER          | FK (REFERENCES GroupClasses), NOT NULL |
 | TrainerID         | INTEGER          | FK (REFERENCES Trainers)         |
 | BookingDate       | TIMESTAMP        | DEFAULT CURRENT_TIMESTAMP        |
 | Status            | VARCHAR(20)      | DEFAULT 'подтверждена', CHECK(Status IN ('подтверждена', 'отменена', 'посещена', 'не явился')) |

#### **Ограничения:**
- `PK_Enrollments`: PRIMARY KEY (EnrollmentID)
- `FK_Enrollments_Clients`: FOREIGN KEY (ClientID) REFERENCES Clients(ClientID) ON DELETE CASCADE
- `FK_Enrollments_GroupClasses`: FOREIGN KEY (ClassID) REFERENCES GroupClasses(ClassID) ON DELETE CASCADE
- `FK_Enrollments_Trainers`: FOREIGN KEY (TrainerID) REFERENCES Trainers(TrainerID) ON DELETE SET NULL
- `UQ_EnrollmentUnique`: UNIQUE (ClientID, ClassID)
- `CHK_EnrollmentStatus`: CHECK (Status IN ('подтверждена', 'отменена', 'посещена', 'не явился'))

## 🔗 Взаимосвязи

1. **Clients и Enrollments (Один-ко-Многим)**
   - **Описание:** Один клиент может записаться на множество занятий, но каждая запись о занятии относится к одному конкретному клиенту.
   - **Внешний ключ:** `Enrollments.ClientID` ссылается на `Clients.ClientID`.

2. **GroupClasses и Enrollments (Один-ко-Многим)**
   - **Описание:** Одно групповое занятие может иметь множество записей клиентов, но каждая запись относится к одному конкретному типу занятия.
   - **Внешний ключ:** `Enrollments.ClassID` ссылается на `GroupClasses.ClassID`.

3. **Trainers и Enrollments (Один-ко-Многим)**
   - **Описание:** Один тренер может проводить множество занятий, на которые записываются клиенты, но каждая запись относится к одному тренеру.
   - **Внешний ключ:** `Enrollments.TrainerID` ссылается на `Trainers.TrainerID`.
